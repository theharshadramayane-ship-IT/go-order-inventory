# Go Order & Inventory Backend

A production oriented backend system for order and inventory management, built with Go.

> **Status:** Work in progress project scaffolding stage.

## Project Objective

This project demonstrates strong backend engineering fundamentals by implementing a real world order & inventory workflow, including:

- Secure authentication & role-based authorization
- Product and inventory management with concurrency safety
- Order lifecycle management with transactional integrity
- Redis caching for frequently accessed data
- Automated testing at unit, integration, and API levels
- Containerized deployment with Docker
- CI/CD via GitHub Actions

## Tech Stack

| Layer | Technology |
|---|---|
| Language | Go |
| Database | PostgreSQL |
| Cache | Redis |
| API Style | REST |
| Containerization | Docker |
| CI/CD | GitHub Actions |
| Deployment | AWS |
